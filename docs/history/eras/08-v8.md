## The new core

```
CyphaDIF  —  Differential Information Field Classifier

Architecture derived from first principles, unifying:
  ─ AIXI / Solomonoff  : MDL prior over class complexity (||Δk||_F ≤ C)
  ─ Information Geometry: natural gradient on Gaussian manifold (Cramér-Rao efficient)
  ─ Active Inference / FEP: world prior θ₀ + differential class offsets Δk
  ─ Information Bottleneck: contrastive encoder feedback (Fisher-Rao residuals)

Core invariant:
  Class k model  =  θ₀ ⊕ Δk

Classification:
  y* = argmax_k [ log p(h | θ₀ ⊕ Δk) ] + log p(k | context)

Update (natural gradient, Cramér-Rao optimal):
  Attraction (true class k):   Δk  +=  η · residual(h, θk)
  Repulsion  (wrong class j):  Δj  −=  η · wj · residual(h, θj)
  MDL decay  (all classes):    Δk  *=  (1 − λ)
  World prior (all obs):       θ₀  updated via Welford

Encoder feedback (contrastive):
  When pred ≠ true:  W_enc += η_enc · (r_wrong − r_right) ⊗ raw_features
  where r_k = (h − μk) / vk  is the Fisher-Rao score residual
```
— `Cypha.py:1-30`

The whole design is one idea: **every class is the world prior plus a small offset**, and
learning moves offsets in natural-parameter space. Nothing here is decorative — `θ₀`, `Δk`,
the residuals and the MDL decay are all on the path from input to prediction.

## The source is annotated with the sweep

This is the most direct causal link in the archive, and it is the reason v8's constants look
arbitrary until you know where they came from. Sixteen comments cite a **"poll"** — the
27,524-run hyperparameter sweep analysed in [`../SWEEP_ANALYSIS.md`](../SWEEP_ANALYSIS.md).

```python
_WORLD_LR     = 0.02   # world prior learning rate (poll: ema_alpha_store=0.2, scaled for online)
_TEMP_INIT    = 2.5    # initial softmax temperature (poll: temperature_init=2.5)
_TEMP_FLOOR   = 2.5    # temperature is fixed — poll proves decay=1.0 is optimal
_ALIGN_EVERY  = 500    # encoder alignment interval (poll: consolidate_every=500)
_DELIBERATE_HI= 0.40   # deliberate mode: upper confidence bound (poll: deliberate_thresh=0.4)
```
— `Cypha.py:58, 62, 63, 892, 894`

```python
def _dedup_check(self, label: str) -> None:
    """
    Deduplication (poll: dedup_threshold=0.60, most sensitive parameter).
    If two class differential offsets are cosine-similar > 0.6, apply
    mutual repulsion proportional to the overlap. Prevents two classes
    from collapsing onto the same subspace of the latent space.
    """
```
— `Cypha.py:1043-1049`

and the replay buffer records where it sits in the ranking:

> Motivation: the poll found `replay_ratio=0.30` is the 3rd most sensitive
> — `Cypha.py:907`

**Every one of these matches the sweep data independently.** Re-deriving the marginal effects
from the raw JSONL gives `dedup_threshold` as the only knob carrying real signal, with a
unimodal optimum at 0.6; `temperature_decay` best at 1.0, i.e. no decay; and
`temperature_init` best at 2.5. The source says the same thing in prose, written by whoever
ran the experiment.

The word "poll" appears in **no other archived version** — zero occurrences in v5, v6, v7
*and* the root monolith. The root monolith carries the same values with the annotations
stripped.

### But the sweep profiled the predecessor

The header over the constants block reads:

```python
# Poll-derived constants (from 27,524-config brute-force sweep, top_fit=0.6206)
_DEDUP_THRESH    = 0.60
```
— `Cypha.py:889-890`

and that provenance is looser than it sounds. The sweep's 41-knob tiers vary `K_TARGET`,
`LAMBDA_LP`, `GAIN_K`, `GAIN_RHO` and `GAIN_A` — constants defined in **v3's** header
(`archive/cypha-v3/Cypha.py:20-24`) and present in v3, v4, v5, v6 and v7. They occur **zero
times in v8**. The same is true of `anchor_cap`, `lvq_lr`, `lvq_window` and `dead_staleness`,
which name the v5/v6 `AnchorMemory` prototype store that CyphaDIF does not have, and the
records carry an `n_anchors` field.

So the experiment measured the family-A architecture. Its values were **transplanted** into a
system with a different learning rule, not derived for it. The best `final_acc` the sweep
ever reached is 0.9219.

That does not make the annotations false — `dedup_threshold=0.60` really is the sweep's
most-sensitive knob at its marginal optimum, and `decay=1.0` really is best. It makes them
*inherited*. And two further claims in the v8 README do not survive checking at all: that
`λ = 0.002` was "found empirically via" the sweep (no `mdl_lambda`, `delta_lr` or `enc_lr`
key appears in any of the 27,524 records), and that the final parameters are a top-100
average (the shipped `dedup_threshold = 0.60` is the argmax of the *marginal* mean, which is
not the same selection rule — see
[`../SWEEP_ANALYSIS.md`](../SWEEP_ANALYSIS.md#the-result-that-mattered-two-knobs-were-inert)).

## The benchmark is not reproducible

Fifteen mathematical analyses examined this system taking macro F1 = 1.0000 and zero test
errors as their starting point. Running the shipped code, that result appears in a little
over half of runs.

`run_benchmark(n_train=30, n_test=30, n_epochs=5)` — the file's own standard benchmark —
executed 20 times:

```
macro == 1.0000 in 12/20 runs
the other 8 runs: macro 0.9000, with bin_benign collapsed to 0.00
                  and all nine other classes at 1.00
```

It is close to a coin flip, and the failure is always the same class. A representative
collapsed run's epoch trace is `0.9033 → 0.9000 → 0.9000 → 0.9000 → 0.9000`; a successful
one is `0.9033 → 0.9000 → 0.9000 → 0.9000 → 1.0000`. The system sits at 0.9 for four epochs
and then either escapes or does not.

`bin_benign` and `bin_malware` are the two near-degenerate classes — the binary pair in a
10-class problem otherwise made of five network-traffic and three log-severity categories.
`bin_benign` is also the class with the smallest Fisher–Rao complexity in the diagnostics
(‖Δk‖ ≈ 12.6 against `net_scan`'s 165.5), i.e. the offset closest to the world prior.

### A plausible mechanism, not an established cause

The obvious suspect is the repulsion term:

```python
def repel(self, h, mu0, v0, weight=1.0, lr=_DELTA_LR):
    mu_k = self.mu(mu0)
    self.delta_mu -= lr * min(weight, _REPULSE_CAP) * _mean_residual(h, mu_k)
```
— `Cypha.py:532-535`

With `_DELTA_LR = 0.08` and `_REPULSE_CAP = 0.5`, a maximally-weighted repulsion step is
`0.08 × 0.5 = 0.04`, exactly **half** the attraction step. For two classes the model cannot
separate, the posterior weight `w_j` approaches 0.5 for both, so each keeps pushing the
other away with half the force it pulls itself — a plausible route to winner-take-all.

**Ablating it does not fix the instability.** Replacing `ClassDifferential.repel` with a
no-op and re-running the same 20 trials:

```
baseline            macro == 1.0000 in 12/20
repulsion disabled  macro == 1.0000 in 14/20
```

14 against 12 out of 20 is within noise. The repulsion runaway is a reasonable reading of
the code, but it is **not** demonstrated to be the cause, and this document does not claim
it is. What is established is the instability itself and which class fails.

*(Measured on Python 3.11.15 / NumPy 2.4.6; the original environment is unknown and
iteration order over Python containers can differ between interpreters, so absolute rates
may move. The instability reproduced on every attempt.)*

### Why this matters for the papers

The v8 analyses are careful work, and their central move — treating a perfect score as a
reason to investigate rather than a result — is the right instinct. But fifteen documents
studied the structure of a system whose headline number does not reliably reproduce, and
none of them reports having run the benchmark twice. The synthesis names "incomplete
convergence (79.9% at end of training)" among its five failure modes, which is adjacent to
this, but it does not identify that the reported 1.0000 is a coin flip.

An archive-wide pattern closes here. v4 reported a modality accuracy that could not fail,
v6 evaluated on a set it was still learning from, and v8 produced fifteen mathematical
audits of a benchmark result that holds about 60% of the time. The measurement culture
improved enormously across those versions; verifying that the headline number is stable was
the step still missing.

## What happened next

Three days later, the archive's newest file — `archive/root-monolith/Cypha.py` — is
CyphaDIF "v2", 5,346 lines, with an explicit enhancement list:

> Phase 1 — Tiered context: 3-tier `TieredContextBuffer` (short/mid/long), `NIGField` τ=0.99
> group, field confidence wired into context prior blending.
> Phase 2 — Generation overhaul: temperature-scaled, field-conditioned, boundary
> interpolation, adversarial, OOD, MDL-ball constrained, ancestral, KDE.
> Phase 3 — Active learning & anomaly: `anomaly_score()`, `active_query_score()`,
> `drift_score()`, `infer_full()`.
> Phase 4 — Priority replay: recency+surprise weighted, 10k capacity, KDE generation.
> Phase 5 — Sequence & multi-modal: `predict_next()`, `ConcatEncoder`, `MultiModalCyphaDIF`
> with per-encoder LLR fusion.

Phase 2 and Phase 5 are v7's generation work rebuilt on the new core. Phase 4 is the replay
buffer scaled 5×. And that file is the one the native C++ was ported from — see
[`../PYTHON_TO_CPP_BRIDGE.md`](../PYTHON_TO_CPP_BRIDGE.md).

## How to read this era

v8 is the shortest version since v4 and the only one whose every component is on the critical
path. It was not designed in isolation: its constants carry citations to a 1,070-core-hour
experiment; its predecessor's causal matrix came with it; and within days it acquired fifteen
independent mathematical audits.

Two of those inheritances are weaker than they look. The experiment profiled the *previous*
architecture — five of the knobs it swept do not exist in v8 — so the constants are
transplanted rather than fitted. And the perfect score the audits set out from reproduces in
about 12 runs in 20.

Neither observation diminishes what v8 got right, which is considerable: a small core where
every equation is load-bearing, constants that carry their provenance in the source, and a
posture that treats a perfect score as a reason to look harder. Those habits are what
survived thirteen months of resonance mathematics, and they are what shipped. The last
missing step — checking that the headline number is stable before analysing it fifteen ways —
is the one the native product's pinned regression baselines and golden fixtures eventually
supply.
