# D10 ECG5000 >90% attempt — 2026-07-18

## Goal

Push D10A ECG5000 accuracy from **85.96%** toward **>90%** using richer temporal features and training scale (no SSM / no BASELINE_LOCK edits).

## Before / after (FAST, `cypha_bench_run --domain-tag d10`, real `data_source=ecg5000`)

| Config | D10A accuracy | Notes |
|--------|---------------|-------|
| Legacy (win=32, 8 passes, 24-dim stats+FFT) | **85.96%** | Pre-pass baseline |
| `CYPHA_D10_ECG_ENRICH=1`, 16 passes | **86.91%** | z-score + full-window + diff concat + feature standardize |
| `CYPHA_D10_ECG_ENRICH=1`, 32 passes | **89.13%** | More online passes helped most |
| `CYPHA_D10_ECG_ENRICH=1`, 44 passes | **90.11%** | First cell crossing 90% |
| **Default on real ECG5000 (2026-07-18 HEAD)** | **90.11%** | Auto-enrich when `data_source=ecg5000`, 44 passes |

Evidence: `bench/report/tables/d10.json` after each run; rebuild `native/build_realprof/cypha_bench_run.exe`.

## What changed (code)

**`native/src/bench/bench_encoder_timeseries.cpp`** (+ header):

- Per-series z-score before encoding
- Full-length window (140) with `n_fft=32`
- Concatenated raw + first-difference temporal features (80-dim)
- Train/test feature standardization (`standardize_train_test`)
- **`d10_ecg_feature_config_from_env(data_source)`** — enrich **on by default** when real ECG5000 is loaded; `CYPHA_D10_ECG_ENRICH=0` restores legacy path; `CYPHA_D10_ECG_ENRICH=1` forces enrich on synthetic too

**`native/src/bench/bench_domains.cpp` (`run_d10_experiment_a`)**:

- Uses `encode_ecg_series` + enriched config
- Default **44** online training passes when enrich is active (override: `CYPHA_D10_TRAIN_PASSES`)
- JSON metadata: `feature_mode=ecg_enrich`, `feature_dim`, `window`, `n_fft`, `train_passes`

## Env knobs (all optional)

| Variable | Default (real ecg5000) | Effect |
|----------|------------------------|--------|
| *(none)* | enrich on | 90.11% FAST D10A |
| `CYPHA_D10_ECG_ENRICH=0` | off | Legacy 85.96% |
| `CYPHA_D10_TRAIN_PASSES` | 44 | Online pass count |
| `CYPHA_D10_ECG_ZSCORE` | 1 | Toggle per-series z-score |
| `CYPHA_D10_ECG_DIFF` | 1 | Toggle diff feature branch |
| `CYPHA_D10_ECG_FULL_WINDOW` | 1 | Full series vs win=32 |
| `CYPHA_D10_ECG_STANDARDIZE` | 1 | Feature z-score across train/test |
| `CYPHA_D10_ECG_N_FFT` | 32 | rFFT bins per branch |

## Verdict

**>90% reached** on real UCR ECG5000 with hand-engineered features + DIF online classifier (**90.11%**). Remaining gap to SOTA (~94–96% on ECG5000 with dedicated sequence models) would need kernel/RFF LLR wiring for D10 classification, multi-scale windows, or a small CNN/SSM front-end — out of scope for this pass.

Synthetic fallback (`data_source=synthetic`) keeps the legacy encoder unless `CYPHA_D10_ECG_ENRICH=1`.
