## The simplification

v3 deletes the entire framework stack. v2 required `torch`, `ray` and `scipy`; v3 requires
`numpy` and nothing else. The core file shrinks **5.8× by bytes and 6.4× by lines**
(364,400 → 62,433 B; 9,404 → 1,481 lines), and classes drop from 49 to 30.

This is the decision that eventually made a C++ port possible. From here to the end of the
main line, every kernel is hand-written against plain arrays — there is no framework to
port, only arithmetic. PyTorch never returns to the main line
(see [`../PYTHON_TO_CPP_BRIDGE.md`](../PYTHON_TO_CPP_BRIDGE.md#why-a-c-rewrite-was-available-at-all)).

v3 is also the first version to **actually compose** the HLFC pipeline that v2 specified but
applied in parallel:

```python
return self.df.fold(self.cl.map(self.se.encode(self.fe.extract(x))))
```
— `Cypha.py:333`

## Two programs in one directory

`Cypha_Encoder.py` ("CyphaMicro", 64-D) and `Cypha.py` (4096-D) are independent programs
with different encoders and different retrieval strategies. CyphaMicro is the honest small
prototype: content-defined chunking → D4 wavelet moments → a 256-bin DAMR reservoir
histogram → importance selection to 64 dims, then PhaseBridge → ResonanceField → Resonator
→ `AnchorMemory` keyed on **the resonator output**. Its `AdaptiveControlLoop` genuinely
closes: changing `EncoderParams` measurably changes the encoder's output.

`Cypha.py` keeps the class names and replaces the algorithms. Its `BinaryEncoder` has no
wavelet, no content-defined chunking and no DAMR reservoir. It is a 4096-D hashed n-gram
bag — 1024 unigram buckets with U-shaped position weighting, 1024 bigram, 1024 trigram —
plus 86 hand-engineered structural dims and 40 verbatim prefix bytes, L2-normalised.

The seventeen numbered sections of `Cypha.py` map one-to-one onto v2's ten layers, so the
whole HRNA design is finally readable end to end in 1,481 lines. `forward()` (`:1140`) runs
the full pipeline: encode → 6×(inject + evolve) → HLFC compress → gather events → modulate
→ horizontal + temporal recursion → resonator → assembly → module → global → blend three
feedback terms `0.7·G + 0.1·fb_res + 0.1·fb_temp + 0.1·fb_crit` → thought cascades →
vertical recursion → L2-normalised state.

## The core is computed and discarded

`train_step` runs `forward()`, computes the contrastive loss, feeds it to the control loop —
and then stores an anchor built from the **raw encoder features**, not the dynamical state:

```python
enc_in = self.bin_enc.encode_text(inp, self.params)   # computed, never read
anchor = self.encode_features(inp)                     # <- what is actually stored
self.memory.store(inp, anchor, out)
```
— `Cypha.py:1224-1226`

`infer` does the same thing:

```python
res = self.forward(text)                                    # <- discarded
anchor_q = self.bin_enc.encode_text(text, self.params)      # <- what is actually queried
matches = self.memory.lookup(anchor_q, k=3)
```
— `Cypha.py:1290-1292`

Retrieval is therefore 1-NN cosine over 4096-D n-gram hash vectors. The resonance field, the
four-level hierarchy, the event system, the recursion operators, the feedback controllers
and the thought processor are all computed on every call and contribute **nothing** to the
answer.

### Verified by ablation

Replacing `Cypha.forward` with a function that returns a constant zero state, and training
on the first 200 pairs of `data.txt`:

```
FULL     train=   1.18s  recall=200/200
ABLATED  train=   0.09s  recall=200/200   speedup=13x
```

Identical recall. The entire HRNA dynamical core is removable without changing a single
prediction.

This was not obviously a mistake. CyphaMicro, which *does* retrieve from resonance space,
is measurably non-deterministic — repeated `infer('cat sound')` returns different answers
across calls, and it manages 7/14 recall on its own training set. Moving the anchor key
from the dynamical state to the encoder features is what made v3 work at all. The cost is
that the architecture the project is named after stopped being load-bearing, and nothing in
the file says so.

A related tell sits two lines above: every training example and every inference begins by
resetting all five stateful levels, under the comment **"critical, prevents state bleed"**
(`:1209-1210`, `:1287-1288`) — a candid admission that the recurrent dynamics were
contaminating supervision rather than contributing to it.

## Other machinery that does not run

| Component | Status |
|---|---|
| **HLFC compression** | computed every forward pass (`:1148`), returned in the result dict (`:1199`), never read. `decompress`, `add`, `reconstruct` and `unfold` are never invoked. 0.26 ms/forward of pure overhead. |
| **The adaptive encoder loop** | `BinaryEncoder.encode(self, data, p)` never dereferences `p`. Encoding the same text under `EncoderParams(chunk_k=4, ρ=3, 4 scales)` and `(chunk_k=8, ρ=8, 1 scale)` yields bitwise-identical vectors. `AdaptiveControlLoop` still runs and still logs `k` and `ρ` — steering a wheel connected to nothing. |
| **Multicore execution** | `N_WORKERS`, `_POOL`, `_LOCK`, `WorkStealer`, `SparseComputer` all declared, never used. `forward()` even defines `_resonator()` and `_assembly()` closures for parallel dispatch (`:1159-1160`) then runs the levels sequentially below. `main()` prints "CPU multicore (N workers)". |
| **Scheduled / queued events** | `EventScheduler.schedule` and `ResonanceField.queue_event` are never called, so `pop_due()` always returns `[]` and the Dirac-delta injection branch is unreachable. `ModuleLevel.add_memory_event` is never called, so working memory stays identically zero. |
| **SURPRISE events** | with `surp_thr=0.15`, none ever fire (a measured run: 131 events, 100% RESONANCE). v4 drops the threshold to 0.01 and `theta_thought` from 0.7 to 0.1 to make the machinery emit anything. |
| **Multimodal input** | `encode_array` takes a parameter named `raw` but references `raw_bytes` (`:151-156`), raising `NameError` on every call. Every call site wraps it in a bare `except`, so the failure is silent, and all 64 `arr:`/`hex:` examples in `data.txt` are encoded as the ASCII text of their own base64/hex payload. |

The `encode_array` bug is worth stating plainly: v3's multimodal support does not merely
degrade, it never executes. v4 fixes the `NameError`; v5 documents the residual train/infer
mismatch as "FIX B2".

## Claims that do not survive contact with the code

| Claim | Reality |
|---|---|
| `Cypha.py:2` "Binary+Cypha Universal Encoder" | the v3 `BinaryEncoder` contains no wavelet, no content-defined chunking, no DAMR reservoir. Those exist only in `Cypha_Encoder.py`. The name survived the rewrite; the algorithm did not. |
| `Cypha.py:5` "Multicore CPU via concurrent.futures" | strictly single-threaded; the pool is never submitted to |
| `Cypha_Encoder.py:7` `y_t = AnchorMatch(ψ_t, Memory)` | true in `Cypha_Encoder.py`, false in `Cypha.py`, where ψ is discarded |
| `Cypha_Encoder.py:17` "Adaptive Control Loop (NO gradients — pure field-driven parameter adaptation)" | the loop is open in `Cypha.py`: the encoder ignores its parameters |
| `wavelet_signature` (`:909`) returning "smooth(text-like)" / "structured(image-like)" / "spiky(binary-like)" | no wavelet is computed; the "detail" half is the trigram hash block. Measured: `'capital of France'` → "structured(image-like)", `'12+165'` → "structured(image-like)". The labels do not track modality. |
| v2's "~500,000:1 practical compression" | v3 never measures a ratio, and the output dict retains the full 32-component residual plus a reference to the 256-element lattice |

## What v3 contributes

Despite the above, v3 is where several durable things start.

- **The dependency floor.** numpy-only, permanently. This is the precondition for everything
  that follows, including the native port.
- **The feature-space-first representation.** Hashed n-gram features plus hand-engineered
  structural dims survive into v4 and are only superseded by `OmegaEncoder` in v5.
- **Composed HLFC** (`:333`) — the first working version of v2's specified operator, even
  though its output is unused.
- **Diagnostic instrumentation.** `ModalityDetector` with per-modality accuracy bars,
  `AnchorMemory.separation_stats` with a "⚠ COLLAPSING" warning when the minimum pairwise
  cosine distance drops below 0.05, `EventGenerator.type_report`, and a `sep` REPL command
  printing the anchor cosine matrix. Measuring the model's own health becomes a habit here.
- **A deterministic synthetic benchmark.** `generate_data.py` (seeded 42/42) produces 500
  examples across ten declared modalities — the ancestor of v5 and v6's
  `synthetic_benchmark.py`.

## The pattern this era establishes

v2 computed its compression and threw the result away. v3 computes its entire dynamical core
and throws the result away. In both cases the architecture document describes the discarded
path as the mechanism.

This recurs, and it is the best explanation available for why v8 was a clean-sheet restart
rather than a refactor: after five more versions of accumulating machinery on top of a core
that was never load-bearing, starting from a small set of equations that are *all* on the
critical path was the cheaper move.

It breaks exactly once. v7's `CyphaDecoder.generate()` primes the field with a full
`forward()` pass and decodes tokens directly from the resulting state — the one path in the
archive where the architecture determines the output. See
[`07-v7-generation.md`](07-v7-generation.md#cyphadecoder--the-first-real-gradient-learning-on-the-main-line).
Classification never does.
