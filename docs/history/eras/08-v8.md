## The new core

```
CyphaDIF  —  Differential Information Field Classifier

Architecture derived from first principles, unifying:
  ─ AIXI / Solomonoff  : MDL prior over class complexity (||Δk||_F ≤ C)
  ─ Information Geometry: natural gradient on Gaussian manifold (Cramér-Rao efficient)
  ─ Active Inference / FEP: world prior θ₀ + differential class offsets Δk
  ─ Information Bottleneck: contrastive encoder feedback (Fisher-Rao residuals)

Core invariant:
  Class k model  =  θ₀ ⊕ Δk

Classification:
  y* = argmax_k [ log p(h | θ₀ ⊕ Δk) ] + log p(k | context)

Update (natural gradient, Cramér-Rao optimal):
  Attraction (true class k):   Δk  +=  η · residual(h, θk)
  Repulsion  (wrong class j):  Δj  −=  η · wj · residual(h, θj)
  MDL decay  (all classes):    Δk  *=  (1 − λ)
  World prior (all obs):       θ₀  updated via Welford

Encoder feedback (contrastive):
  When pred ≠ true:  W_enc += η_enc · (r_wrong − r_right) ⊗ raw_features
  where r_k = (h − μk) / vk  is the Fisher-Rao score residual
```
— `Cypha.py:1-30`

The whole design is one idea: **every class is the world prior plus a small offset**, and
learning moves offsets in natural-parameter space. Nothing here is decorative — `θ₀`, `Δk`,
the residuals and the MDL decay are all on the path from input to prediction.

## The source is annotated with the sweep

This is the most direct causal link in the archive, and it is the reason v8's constants look
arbitrary until you know where they came from. Sixteen comments cite a **"poll"** — the
27,524-run hyperparameter sweep analysed in [`../SWEEP_ANALYSIS.md`](../SWEEP_ANALYSIS.md).

```python
_WORLD_LR     = 0.02   # world prior learning rate (poll: ema_alpha_store=0.2, scaled for online)
_TEMP_INIT    = 2.5    # initial softmax temperature (poll: temperature_init=2.5)
_TEMP_FLOOR   = 2.5    # temperature is fixed — poll proves decay=1.0 is optimal
_ALIGN_EVERY  = 500    # encoder alignment interval (poll: consolidate_every=500)
_DELIBERATE_HI= 0.40   # deliberate mode: upper confidence bound (poll: deliberate_thresh=0.4)
```

and the replay buffer records where it sits in the ranking:

> Motivation: the poll found `replay_ratio=0.30` is the 3rd most sensitive

**Every one of these matches the sweep data independently.** Re-deriving the marginal effects
from the raw JSONL gives `dedup_threshold` as the only knob carrying real signal, with a
unimodal optimum at 0.6; `temperature_decay` best at 1.0, i.e. no decay; and
`temperature_init` best at 2.5. The source says the same thing in prose, written by whoever
ran the experiment.

The word "poll" appears in **no other archived version** — zero occurrences in v5, v6, v7
*and* the root monolith. The root monolith carries the same values with the annotations
stripped. So v8 is the first version built on the sweep, which places the sweep in the
v6/v7 window and explains why its `archetype` field uses v6's profiler-4 vocabulary.

One small inconsistency survives: `_DELIBERATE_HI = 0.40` at `:894`, while the comment at
`:1112` reads "deliberate_lo=0.10, deliberate_hi=0.35". The root monolith settles on
`_DELIBERATE_LO = 0.25`, `_DELIBERATE_HI = 0.40`.

## What crossed the gap from v7

v8 shares **zero class names** with v7. It is not, however, a blank page.

`W_T` — the online-learned causal transition matrix introduced in v7 — is here, with the
same rank-1 outer-product update written in error-descent form, plus a new spectral-radius
bound:

```python
# Spectral radius of W_T maintained ≤ 0.85 via power iteration.
self._W_T    = W / (sr + _EPS) * 0.05
self._A_eff  = (np.diag(self._a) + self._W_T).astype(np.float32)
...
def update_causal(self, h_t, h_target, ...):
    err   = self._W_T @ h_t - h_target
    W_new = self._W_T - lr * np.outer(err, h_t) / self.d
```

`update_causal` is new at v8. Both it and `W_T` ship today as `nig_field_update_causal` (see

`cypha_synthesis.md` unifies them into a prioritised upgrade roadmap, and it is unusually
candid about what it found. Five strengths: exact Bayes-optimal decision boundaries
(t* = 0.5000 for all 45 class pairs), a globally stable attractor (17,792 negative Lyapunov
exponents, Kaplan–Yorke dimension 0), channel capacity at 101.7% of the theoretical maximum,
126.8° phase margin, and escape times from 10⁴ to 10¹⁶ steps.

Five failure modes, stated as plainly:

1. **systematic calibration failure** — ECE 0.191, temperature 25× above optimal;
2. **MDL-induced mean attenuation** — G = 0.625, a 37.5% shrinkage;
3. **dimension inefficiency** — 9 signal dimensions in a 128-D space, a 14× gap;
4. **basin prior-mismatch** — `net_normal` captures 69.5% of the Gaussian mass;
5. **incomplete convergence** — 79.9% at the end of training.

The task these were measured on was 10-class network-security classification
(`net_normal`, `net_scan`, `net_ddos`, `net_exfil`, `net_c2`, `log_info`, `log_warn`,
`log_error`, `bin_malware`, `bin_benign`), 3,000 labelled samples, 3 epochs, reporting macro
F1 = 1.0000 and zero test errors on 2,000 fresh samples.

That last figure is why the analyses exist. The synthesis opens by noting that the system is
empirically perfect on its benchmark and then asks what is structurally true anyway —
"properties that will cause failures under distribution shift, adversarial inputs, or
deployment conditions differing from the training distribution". Given how much of the
earlier archive reports metrics that cannot fail (v4's tautological 100% modality accuracy,
v6's live-learning evaluation set), an F1 of 1.0000 treated as a *reason to investigate
further* is a real change of posture.

The papers are the archive's most valuable non-code artifact, and the upgrade roadmap they
produce is the immediate input to the five phases the root monolith then implements.

## What happened next

Three days later, the archive's newest file — `archive/root-monolith/Cypha.py` — is
CyphaDIF "v2", 5,346 lines, with an explicit enhancement list:

> Phase 1 — Tiered context: 3-tier `TieredContextBuffer` (short/mid/long), `NIGField` τ=0.99
> group, field confidence wired into context prior blending.
> Phase 2 — Generation overhaul: temperature-scaled, field-conditioned, boundary
> interpolation, adversarial, OOD, MDL-ball constrained, ancestral, KDE.
> Phase 3 — Active learning & anomaly: `anomaly_score()`, `active_query_score()`,
> `drift_score()`, `infer_full()`.
> Phase 4 — Priority replay: recency+surprise weighted, 10k capacity, KDE generation.
> Phase 5 — Sequence & multi-modal: `predict_next()`, `ConcatEncoder`, `MultiModalCyphaDIF`
> with per-encoder LLR fusion.

Phase 2 and Phase 5 are v7's generation work rebuilt on the new core. Phase 4 is the replay
buffer scaled 5×. And that file is the one the native C++ was ported from — see
[`../PYTHON_TO_CPP_BRIDGE.md`](../PYTHON_TO_CPP_BRIDGE.md).

## How to read this era

v8 is the shortest version since v4 and the only one whose every component is on the critical
path. It was not designed in isolation: its constants are the output of a 1,070-core-hour
experiment, annotated in the source; its predecessor's causal matrix came with it; and within
days it acquired fifteen independent mathematical audits that named five concrete failure
modes in a system scoring a perfect F1.

The three habits that survive from the thirteen months before it — measure before deciding,
record why a constant has its value, and treat a perfect score as suspicious — are all
visible in this one file. The resonance mathematics is gone. The engineering culture that
produced it is what shipped.
