## What the patch got right: the field is now actually nonlinear

v3's resonance-field nonlinearity was numerically almost a no-op, and v4 fixes it.

```python
# v3 (cypha-v3/Cypha.py:385)   amplitude-additive, γ=0.3, dt=0.2
ψ ← ψ + γ·dt·(|ψ|²−1)·ψ ;  ψ ← ψ/‖ψ‖

# v4 (cypha-v4/Cypha.py:383-385)  phase-multiplicative, γ=5.0, dt=0.3
n = γ(|ψ|²−1)ψ ;  ψ ← ψ·exp(−i·dt·Re(n)) ;  ψ ← ψ/‖ψ‖
```

ψ is renormalised to `‖ψ‖₂ = 1` over 256 components, so `mean|ψᵢ|² = 1/256 ≈ 0.0039` and
`(|ψᵢ|² − 1) ≈ −1` everywhere. v3's update therefore reduced to a near-uniform rescale
whose across-component differential is `O(γ·dt·max|ψᵢ|²) ≈ 0.001` — and the normalisation on
the next line cancelled the uniform part. Measured: after 20 steps, v3's nonlinear evolution
differs from a purely linear one by `‖Δ‖_∞ = 0.0038`, on a field whose components are ~0.06.

v4's form is a per-component **phase rotation**, which is exactly norm-preserving and so
survives the normalisation intact. Measured divergence from linear-only evolution: 0.088
after 5 steps, 0.294 after 20, against `‖ψ‖_∞ ≈ 0.16`.

The fix is real. The form is not standard, though: a Gross–Pitaevskii split-step would use
`exp(−i·dt·γ(|ψ|²−1))`. Taking `.real` *after* multiplying by ψ makes the rotation angle
depend on `Re(ψᵢ)`, which is basis-dependent and has no physical reading.

## What the patch made ambiguous: two incompatible κ

v4 introduces a new definition of criticality without removing the old one.

| | Formula | Location | Read by |
|---|---|---|---|
| **old** | `κ = mean(\|ψ − ψ_prev\|²)` — temporal change | `FieldStats`, `:399` | `AdaptiveControlLoop.update` (`:999`), `Metrics.criticality` (`:1244`), the training and inference print lines (`:1272`, `:1324`) |
| **new** | `κ = (Σ_top10 \|ψᵢ\| / Σᵢ \|ψᵢ\|) · Var(\|ψ\|) · 100` — spectral concentration | `criticality()`, `:408-415` | `showcase` (`:1389`, `:1400`) and `verify_thinking.py` only |

Different quantities, different units, different consumers, same name. The training banner
prints `Field: κ=0.0040` and `showcase` prints a κ from the other formula; **any document
treating them as the same number is wrong.** The new formula is the one that becomes
canonical — v5 and v6 copy it verbatim, and
`DOCX/Cypha v5/README_Cypha.md:115` documents it as *the* κ.

### A bound the code does not respect

With `‖ψ‖₂ = 1` over `N` components, `Var(|ψ|) = E[|ψ|²] − (E[|ψ|])² ≤ 1/N`, and
concentration ≤ 1. So

```
κ ≤ 100/N  =  100/256  =  0.3906
```

Verified numerically — all mass in one component gives **κ = 0.38910**, and a 200,000-sample
random search over sparse fields finds nothing higher:

```
all mass in 1 component : kappa=0.38910   (theory 100/N = 0.39062)
mass spread over 10     : kappa=0.37537
uniform                 : kappa=0.00000
best of 200k random     : kappa=0.38910
```

`showcase` therefore contains a branch that can never execute:

```python
if κ > 0.7:
    print(f"    ⚡ CRITICAL — thought cascade triggered")
    break
```
— `Cypha.py:1406-1408`

And `verify_thinking.py`'s checklist item "Critical threshold possible"
(`max(kappa_vals) > 0.1`, `:176`) is not reachable in practice either — measured
post-showcase κ runs 0.027–0.075, and the harness duly reports ✗.

## What the patch manufactured: the thinking

Two thresholds were lowered, and one reset was omitted. Together they are the whole
demonstration.

| Constant | v3 | v4 | Change |
|---|---|---|---|
| `EventGenerator` surprise threshold | 0.15 (`v3:635`) | 0.01 (`v4:640`) | **15× lower** |
| `ThoughtProcessor.theta_thought` | 0.7 (`v3:780`) | 0.1 (`v4:785`) | **7× lower** |

`cascade` is unchanged in form: a trigger with priority `p > θ` spawns three THOUGHT
sub-events at delays {0.01, 0.05, 0.1} with priorities {0.8p, 0.5p, 0.3p}. The subtree size
obeys `N(p) = Σ_{s ∈ {0.8,0.5,0.3}} (1 + N(p·s))` for `p > θ`, giving

```
N(0.5) = 81     N(0.6) = 102     N(1.0) = 318     N(2.0) = 1233
```

RESONANCE events carry `priority = enhanced_resonance > res_thr = 0.5`, so under v4 **every
single one detonates a tree of at least 81 nodes**. Under v3's θ = 0.7 a resonance event at
r ≈ 0.5–0.7 produced nothing at all. A measured showcase run emits **11,163 THOUGHT events
against 50 RESONANCE and 9 SURPRISE** — 99.5% of the activity is the cascade constant.

### The reset asymmetry

`train_step` (`:1216`) and `infer` (`:1295`) both begin by resetting all five stateful
levels. **`showcase` (`:1361`) does not.** That asymmetry is the entire experimental
apparatus behind the persistence claim: it creates the one code path where dynamical state
survives between queries.

`verify_thinking.py` then measures exactly that. State does persist — but the κ ramp it
reports is content-independent. Reversing the input order reproduces the same ascending
sequence (0.0462 → 0.0609 → 0.0708), and repeating a single input five times ramps too
(0.0342 → 0.0792). The harness measures the absence of a `reset()` call, not cognition. And
the state it measures still has no influence on any answer, because `infer` resets and then
ignores `res` anyway.

### The checklist

```python
checks = [
    ("κ > 0.01 achieved",            max(kappa_vals) > 0.01 ...),
    ("Multiple event types",          True),  # We'll check manually
    ("Events increasing over steps",  True),  # We'll check manually
    ("Critical threshold possible",   max(kappa_vals) > 0.1 ...),
    ("State persistence",             kappa_vals[-1] > kappa_vals[0] ...),
]
```
— `verify_thinking.py:172-178`

Two of the five items are literal `True`. Any transcript reporting 4/5 or 5/5 is really
2/3 or 3/3.

## Other tautological measurements

- **"Modality accuracy: 100.0%"** across all seven buckets (`Cypha.py:1234-1238`) compares
  `memory.get_output(inp)` against `out` immediately after `memory.store(inp, ..., out)`.
  It cannot report anything else.
- **`self_retrieval_rate=1.000`** (`verify_thinking.py:61`) is fixed by the diagonal
  overwrite at `Cypha.py:987`. It is not evidence that anchors are separable.
- **`DOCX/Cypha v5/README_Cypha.md:116`** — "The AdaptiveControlLoop uses κ to tune injection
  parameters in real time" — is false for v4 twice over: the control loop reads the *other*
  κ, and its outputs (`chunk_k`, `damr_radius`, `active_scales`) are still never read by any
  encoder, exactly as in v3.

## What v4 genuinely contributes

**`benchmark_suite.py` is the archive's first external-evaluation posture.** Eight synthetic
defence-relevant tasks — RF and acoustic signal classification, network-intrusion JSON,
malware opcode sequences, byte-pattern detection, 8×8 vehicle silhouettes, multivariate
sensor traces, SQL/command/XSS injection strings, and protocol banners — each run head to
head against a `TfidfVectorizer(char 1-3gram)` + `RandomForestClassifier(n_estimators=100)`
baseline, writing an auto-generated `benchmark_results.md`.

After three versions of asserting speedups copied from conversation transcripts, this is the
first time Cypha is measured against something it did not define. The methodology thread
runs from here to the pinned regression baselines in the current `bench/` tree.

**`showcase()`** itself is durable: v5 and v6 inherit it byte-identically.

**The nonlinearity fix** is real and carries forward.

---

## How to read this era

v4 is the clearest case in the archive of a demonstration being built rather than found. The
release is organised around showing that Cypha "thinks"; the evidence for it is a reset that
was left out, two thresholds lowered by 7× and 15×, a checklist with two hardcoded passes,
and a critical-state banner that is mathematically unreachable.

None of that makes the version worthless — the field nonlinearity fix is correct and the
benchmark suite is a real step forward. But the thinking demonstration does not survive
inspection, and the v5 documentation inherits its claims.
