## Background & Theoretical Basis

A neural network is simultaneously four overlapping mechanisms:

1. **Lossy compression (distribution compression, GRIA α→1):** The weight matrix θ* compresses the training distribution P(Y|X). Individual examples are lost (empirically α≈0.9997). What survives is the statistical shape of the data — a distributionally lossless, instance-lossy encoding. This is the irreversible GRIA channel.

2. **Lossless compression (residual channel, GRIA α→0):** High-frequency facts, exact syntactic patterns, and common sequences survive because the distribution *is* their lossless encoding when the prior is strong enough. The NIG epistemic uncertainty is the formal proxy for this residual — high epistemic uncertainty = data not yet compressed, low = collapsed into the prior.

3. **Statistical algorithm — P(Y|X) approximation:** Attention is kernel regression. MLP is universal function approximation. Softmax is density estimation. All done implicitly, without uncertainty quantification, encoded purely in activation geometry.

4. **Self-organising network (α≈0.5, edge of chaos):** No neuron is programmed for syntax or semantics. These emerge from gradient descent. The Grand Unified Law (α = 1 − H(f(X))/H(X)) governs the complexity of each layer's transformation. At α≈0.5, information transfer per parameter is maximised.

CyphaLM replaces each mechanism with its explicit, efficient CyphaDIF/GRIA/CellAI equivalent:

| NN Mechanism | CyphaLM Equivalent |
|---|---|
| Embedding table (O(V×d) params) | Izaac GF(2ⁿ) permutation polynomial embeddings |
| Attention (O(n²) per layer) | CellAI multi-scale SSM state (O(n) per sequence) |
| MLP + routing | CyphaDIF K-expert NIG field |
| Output softmax + unembedding matrix | GRIA α-projection at α≈0.5 per output class |
| None (no uncertainty) | Explicit NIG epistemic/aleatoric split throughout |

## Phase 1 — Izaac GF(2ⁿ) Token Embeddings

### 1.1 Theory

A token ID `t ∈ {0,...,V-1}` is embedded into R^d via a permutation polynomial over GF(2^n) where 2^n ≥ V.

The permutation polynomial p(x) = a·x^(2^k + 1) + b over GF(2^n) is bijective by construction (no two tokens map to the same vector). The embedding of token t is the binary coefficient vector of p(t), extended to d dimensions via n-bit blocks.

Key properties:
- Zero learned parameters — the field arithmetic defines the structure
- Bijective — no embedding collapse
- Algebraically structured — GF(2^n) distance between token IDs reflects frequency-rank proximity if vocabulary is sorted by frequency

### 1.2 Implementation Spec

## Phase 2 — CellAI SSM Temporal Layer

### 2.1 Theory

CellAI's multi-scale exponential memory kernel is a rank-2 SSM. For input sequence e_1, e_2, ..., e_t (embedding vectors):

```
h_t = λ_fast · h_{t-1} + (1 - λ_fast) · W_fast · e_t    # Fast track
s_t = λ_slow · s_{t-1} + (1 - λ_slow) · W_slow · e_t    # Slow track

λ_fast = exp(-1/τ_fast)
λ_slow = exp(-1/τ_slow)

context_t = concat(h_t, s_t)   # Full context vector, dim = 2 * d_state
```

The Boltzmann transitions (CellAI's memory switching) correspond to the soft routing in CyphaDIF's DIF step — so the CellAI→CyphaDIF interface is a natural handoff: context_t goes directly into the DIF field as the input feature vector.

## Phase 3 — CyphaDIF Expert Field

### 3.1 Theory

The DIF (Discriminative Information Field) routes an input x (the CellAI context vector) to K experts using log-likelihood ratios. Each expert maintains a Normal-Inverse-Gamma (NIG) posterior over the target distribution.

DIF routing: `p(k|x) = softmax([LLR_1(x), ..., LLR_K(x)])`  
NIG per expert k: `p(y | x, k) = StudentT(μ_k, σ²_k, 2α_k)` (predictive posterior)  
Mixture prediction: `ŷ = Σ_k p(k|x) · μ_k`  
Epistemic uncertainty: `σ²_e = Σ_k p(k|x) · (σ²_k / κ_k)` (parameter uncertainty)  
Aleatoric uncertainty: `σ²_a = Σ_k p(k|x) · (β_k / (α_k - 1))` (irreducible noise)

The epistemic uncertainty σ²_e is the explicit lossless residual channel. High σ²_e = the model has not yet compressed this region of input space. Low σ²_e = the region is distributionally encoded.

## Phase 4 — GRIA α-Projection

### 4.1 Theory

The DIF expert mixture produces a continuous vector v ∈ R^d_state. The GRIA α-projection maps this to a probability distribution over the vocabulary:

```
logit_k = α_k · (W · v)_k + (1 - α_k) · bias_k

where:
  α_k ∈ [0,1] is a learnable scalar per vocabulary class
  W   is the output weight matrix
  bias_k captures the unigram marginal (prior knowledge)

P(token=k | v) = softmax(logit_k)
```

At α_k = 1: pure learned projection — maximum context-sensitivity  
At α_k = 0: pure bias — reverts to unigram prior  
At α_k ≈ 0.5: maximises information transfer per parameter (Grand Unified Law)

The bias vector is initialised to the log unigram frequency of each token. This means the model starts with a reasonable prior (common tokens get higher probability) and the learned projection refines it.

## Phase 8 — Research Paper

### Paper Structure

**Title:** CyphaLM: Explicit Compression, Uncertainty, and Self-Organisation for Online Language Modelling

**Target venue:** NeurIPS / ICLR (primary), arXiv preprint first

---

#### Abstract (target 250 words)

Conventional neural language models achieve their capabilities through four simultaneous mechanisms — lossy distribution compression, lossless residual encoding, statistical density estimation, and self-organised feature discovery — all entangled in a single undifferentiated optimisation process. We present CyphaLM, an architecture that makes each mechanism explicit and separately operable. CyphaLM uses: GF(2ⁿ) permutation polynomial embeddings (Izaac) in place of learned embedding tables, eliminating embedding parameters entirely; a multi-scale exponential memory kernel (CellAI) replacing O(n²) attention with O(n) sequence processing; a Normal-Inverse-Gamma expert field (CyphaDIF) providing exact epistemic and aleatoric uncertainty decomposition; and a GRIA α-projection layer whose per-class grade parameter converges to the edge-of-chaos optimum (α≈0.5) during training, in accord with the Grand Unified Law. We demonstrate that CyphaLM's NIG epistemic uncertainty is a calibrated proxy for the lossless residual channel, that DIF experts self-organise by topic without labels, that the architecture adapts to distribution shift online without retraining, and that it does not exhibit catastrophic forgetting. On character-level language modelling benchmarks, CyphaLM achieves competitive bits-per-character at substantially lower parameter counts than transformer baselines, with strict O(n) inference complexity.

## Appendix A — Key Mathematical Identities for Implementation Reference

```
GF(2^n) permutation polynomial:
  p(x) = a·x^(2^k + 1) + b  over GF(2^n)
  Bijective iff a ≠ 0 and gcd(2^k + 1, 2^n - 1) = 1

NIG posterior update (one observation y):
  κ_n  = κ_0 + 1
  μ_n  = (κ_0·μ_0 + y) / κ_n
  α_n  = α_0 + 0.5
  β_n  = β_0 + (κ_0·(y - μ_0)²) / (2·κ_n)

NIG predictive (StudentT):
  mean   = μ_n
  var    = β_n·(κ_n + 1) / (α_n · κ_n)
  df     = 2·α_n

Epistemic variance:    σ²_e = β_n / (κ_n · (α_n - 1))  [parameter uncertainty]
Aleatoric variance:    σ²_a = β_n / (α_n - 1)           [irreducible noise]

CellAI SSM:
  λ_fast = exp(-Δt / τ_fast)
  h_t    = λ_fast · h_{t-1} + (1 - λ_fast) · W_fast · e_t

Grand Unified Law:
  α = 1 - H(f(X)) / H(X)
  where H(X) = -Σ p(x) log p(x)  (Shannon entropy of activation histogram)

GRIA α-projection:
  logit_k = α_k · (W·v)_k + (1 - α_k) · log_unigram_k
  P(k|v)  = softmax(logit)

DIF log-likelihood ratio:
  LLR_k(x) = log p(x | expert_k) - log p(x | prior)
```

## Appendix B — Failure Modes & What They Mean

| Symptom | Likely cause | Fix |
|---|---|---|
| α collapses to 0 or 1 | Learning rate too high on α | Clip α to [0.01, 0.99], reduce lr |
| Expert count explodes | Novelty threshold too low | Raise threshold or cap max_experts |
| Epistemic var → 0 everywhere | NIG prior too strong (κ_0 too high) | Reduce κ_0 to 0.1 |
| Epistemic var stays high forever | NIG prior too weak / SSM not extracting features | Check SSM output is non-degenerate |
| Loss doesn't decrease past bigram | GRIA projection not learning | Check bias initialisation from unigram |
| SSM NaN after many steps | Float32 accumulation | Add periodic layer norm on SSM state |
| Experts don't specialise | DIF field_dim too small | Increase field_dim to 256+ |
