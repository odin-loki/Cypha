# MG3 context warm-up A/B — 2026-07-17

**Scope:** Product adjust on MG3 needle-haystack — try SSM/context warm-up (fact recap + multi-pass prefix) before scoring the needle; keep if absolute `token_recall` gain ≥ 0.1.

## Change

Opt-in flag on `cyphalm_needle_haystack`:

- `--context-warmup` — insert `RECAP: The secret code is [[needle]].` after haystack / before `QUESTION`, and run `warmup_passes` teacher-forced prefix passes at eval (default 2).
- `--warmup-passes N` — override pass count (default 2 when warm-up on; baseline remains 1 pass).

CLI default remains **off**. Smoke defaults warm-up **on** after the measured lift (see below).

Build dir: `native/build_mg3b`.

## Protocol (`CYPHA_BENCH_FAST=1`, seed=42)

| Arm | Flags | Mean token_recall (`recall_rate`) |
|-----|-------|-----------------------------------|
| Before | (default) | **0.05** |
| After | `--context-warmup` | **0.35** |

Per-depth:

| haystack_chars | before token_recall | after token_recall |
|----------------|---------------------|--------------------|
| 32 | 0.00 | 0.20 |
| 64 | 0.10 | 0.50 |

- **Δ recall_rate = +0.30** (≥ 0.1 absolute) → **keep warm-up default-on for smoke**
- Artifacts: `bench/results/needle_haystack_before.json`, `bench/results/needle_haystack_warmup.json`

## Decision

| Criterion | Result |
|-----------|--------|
| Improve ≥ 0.1 absolute? | Yes (+0.30) |
| Smoke default | `--context-warmup` enabled |
| Runner CLI default | still opt-in (`--context-warmup`) |

## Build & re-run

```powershell
cmake -S native -B native/build_mg3b -DCMAKE_BUILD_TYPE=Release -DCYPHA_BUILD_EXPERIMENT_DB=OFF -G Ninja
cmake --build native/build_mg3b --target cyphalm_needle_haystack needle_haystack_smoke
$env:CYPHA_BENCH_FAST=1
native/build_mg3b/cyphalm_needle_haystack.exe --seed 42 --out bench/results/needle_haystack_before.json
native/build_mg3b/cyphalm_needle_haystack.exe --seed 42 --context-warmup --out bench/results/needle_haystack_warmup.json
ctest --test-dir native/build_mg3b -R native_needle_haystack_smoke --output-on-failure
```
